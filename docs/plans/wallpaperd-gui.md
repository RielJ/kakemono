# Implementation Plan: wallpaperd Settings GUI (Wails + React)

## Summary

Add a Wails-based settings GUI to wallpaperd. The GUI is a native macOS window with a React+TypeScript frontend that lets users configure all wallpaperd settings visually — toggle providers, set queries/subreddits, configure intervals, manage favorites, and preview the current wallpaper. The Go backend exposes bound methods that read/write the existing TOML config and communicate with the running daemon via the existing IPC socket.

## Architecture

The GUI is a **separate entry point** (`wallpaperd settings`) that opens a native macOS window. It reuses all existing internal packages.

```
User clicks "Settings" in sketchybar popup
    → wallpaperd settings
    → Wails app opens native window
    → React frontend calls bound Go methods
    → Go methods read/write config.toml + send IPC commands to daemon
```

### Key decisions:
- **Separate Wails binary**: The GUI lives in `gui/` as a Wails sub-project. `wallpaperd settings` spawns it.
- **Bound Go struct**: `SettingsApp` struct exposes methods like `GetConfig()`, `SaveConfig()`, `GetStatus()`, `NextWallpaper()`, etc.
- **React + TypeScript + Tailwind CSS**: Modern, fast, looks good on macOS with proper styling.
- **No separate HTTP API**: Wails bindings handle all Go↔Frontend communication.

## Section 1: Wails Project Setup

### Task 1 — Initialize Wails project structure

Create `gui/` directory with Wails project scaffolding. Don't use `wails init` since we need to integrate with existing project.

Create:
- `gui/main.go` — Wails entry point with `wails.Run()`, embeds `frontend/dist`, binds `SettingsApp`
- `gui/wails.json` — project config pointing to `frontend/`
- `gui/build/appicon.png` — placeholder icon
- `gui/build/darwin/Info.plist` — macOS app metadata

`gui/main.go`:
```go
package main

import (
    "embed"
    "github.com/wailsapp/wails/v2"
    "github.com/wailsapp/wails/v2/pkg/options"
    "github.com/wailsapp/wails/v2/pkg/options/assetserver"
    "github.com/wailsapp/wails/v2/pkg/options/mac"
)

//go:embed all:frontend/dist
var assets embed.FS

func main() {
    app := NewSettingsApp()
    err := wails.Run(&options.App{
        Title:     "wallpaperd Settings",
        Width:     800,
        Height:    600,
        MinWidth:  700,
        MinHeight: 500,
        AssetServer: &assetserver.Options{Assets: assets},
        OnStartup: app.startup,
        Bind:      []interface{}{app},
        Mac: &mac.Options{
            TitleBar: mac.TitleBarHiddenInset(),
            About: &mac.AboutInfo{
                Title:   "wallpaperd Settings",
                Message: "macOS Wallpaper Manager",
            },
        },
    })
    if err != nil { panic(err) }
}
```

### Task 2 — SettingsApp Go backend (bound methods)

File: `gui/app.go`

The SettingsApp struct is bound to the frontend. All its public methods become callable from React.

```go
type SettingsApp struct {
    ctx context.Context
}

// Config methods
func (a *SettingsApp) GetConfig() (*config.Config, error)      // load config.toml
func (a *SettingsApp) SaveConfig(cfg config.Config) error       // write config.toml
func (a *SettingsApp) GetDefaultConfig() config.Config           // return defaults
func (a *SettingsApp) GetConfigPath() string                     // return config file path

// Daemon interaction (via IPC)
func (a *SettingsApp) GetStatus() (*ipc.StatusData, error)       // send "status" to daemon
func (a *SettingsApp) NextWallpaper() error                      // send "next"
func (a *SettingsApp) PrevWallpaper() error                      // send "prev"
func (a *SettingsApp) PauseRotation() error                      // send "pause"
func (a *SettingsApp) ResumeRotation() error                     // send "resume"
func (a *SettingsApp) FavoriteWallpaper() error                  // send "favorite"
func (a *SettingsApp) TrashWallpaper() error                     // send "trash"
func (a *SettingsApp) IsDaemonRunning() bool                     // check socket

// File dialogs
func (a *SettingsApp) SelectDirectory() (string, error)          // native folder picker
func (a *SettingsApp) SelectFile() (string, error)               // native file picker

// Utility
func (a *SettingsApp) OpenFavoritesFolder() error               // open in Finder
func (a *SettingsApp) RestartDaemon() error                      // kill + restart daemon
```

## Section 2: React Frontend Setup

### Task 3 — Initialize React + TypeScript + Vite + Tailwind

Create the frontend project inside `gui/frontend/`:

- `package.json` with React 18, TypeScript, Vite, Tailwind CSS, PostCSS, Autoprefixer
- `vite.config.ts` — standard Vite config
- `tailwind.config.js` — content paths pointing to `src/**`
- `postcss.config.js` — tailwind + autoprefixer
- `tsconfig.json` — strict TS config
- `index.html` — root HTML with `<div id="root">`
- `src/main.tsx` — React DOM render
- `src/App.css` — global styles (macOS-like, draggable titlebar region, dark mode support)

The app should have a macOS-native feel with:
- Sidebar navigation (like System Preferences / Variety)
- Clean, minimal styling
- Dark mode support (respects system theme)
- Draggable title bar area with `--wails-draggable: drag`

### Task 4 — App.tsx with sidebar navigation

File: `gui/frontend/src/App.tsx`

Main layout with left sidebar + right content area. Tabs:
1. **General** — interval, cache size, download dir
2. **Providers** — toggle each provider on/off with per-provider settings
3. **Themes** — light/dark source and query configuration
4. **Favorites** — favorites dir, open folder button
5. **Sketchybar** — enable/disable, item name

Top status bar shows: current wallpaper thumbnail (if available), source name, and quick action buttons (next/prev/fav/trash/pause).

Use React state to hold the config, load it via `GetConfig()` on mount, and save via `SaveConfig()` on changes.

### Task 10 — StatusBar.tsx (wallpaper controls)

File: `gui/frontend/src/components/StatusBar.tsx`
